Keep the layers separate

Submariner: routes cross-cluster traffic through regional gateways.

Lighthouse: synchronizes exported Kubernetes services and answers clusterset.local. OCI API/apps DNS zones remain separate.

Two MySQL Operators: each manages resources in its own OKD cluster.

MySQL ClusterSet: manages asynchronous replication, global PRIMARY/REPLICA roles and controlled switchover.

One database member per site is a lab topology without local failure tolerance. The video uses direct member checks so a regional Router cannot obscure the actual replica role.
